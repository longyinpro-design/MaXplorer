# Milestone：v1.11 — 日常可用

**目标**：让 MaXplorer 从“有亮点的文件浏览器”变成“可以每天替代 Finder 的文件工作台”。

**周期**：单人全职约 4–6 周；兼职按 8–10 周估算。

**发布门槛（Exit Criteria）**：

- [ ] 所有 P0 issue 关闭；P1 要么关闭，要么在 milestone 中明确标注顺延到 v1.12。
- [ ] CI 全绿；新增单测/集成测试/性能基准全部通过；原有 30 项文件操作安全回归不退化。
- [ ] 手动验收通过：搜索 → 选中 → 批量操作 → 撤销；复制/移动预检；取消/重试；压缩/解压；SMB/exFAT/低空间场景。
- [ ] 版本号 1.11、CHANGELOG、README/Help 更新；DMG 与 SHA-256 产出。
- [ ] 没有已知的 P0/P1 数据丢失问题。

**非目标（本阶段不做）**：

- 双面板/分栏（v1.12）
- 压缩包 VFS 浏览、7z/rar、密码压缩包（v1.13）
- SFTP/WebDAV/云盘、文件夹同步、重复文件查找（v1.14+）
- 完整中文本地化迁移、String Catalog、英文版
- AI/语义搜索、插件系统、跨设备索引
- 覆盖操作的撤销/恢复保险库（v1.12+）

**建议 labels**：

`area:search` `area:file-ops` `area:archive` `area:transfer` `area:safety` `area:ui` `priority:P0` `priority:P1` `size:S` `size:M` `size:L` `needs:tests`

# V11-01 [P0] 搜索：递归 + 范围 + 掩码 + 结果视图

**Labels**：`area:search` `priority:P0` `size:L` `needs:tests`  
**Depends on**：—  
**Why**：当前只有当前目录 filter，用户找文件仍然要回 Finder。搜索是 v1.11 的第一优先级。

**Scope**

- 当前目录 filter 保留，性能不退化。
- 新增递归文件名搜索：当前文件夹、当前卷（可选）。
- 支持子串、大小写不敏感、Unicode 归一化、自然排序。
- 支持 glob/mask：`*.jpg`、`report-??.pdf`。
- 结果进入独立虚拟标签页（复用 Space Analyzer/Copy Queue 的特殊标签模式），不覆盖当前文件夹标签。
- 支持“在文件夹中选中匹配项”（Search & Select），不改变列表本身。
- 结果页支持选择、右键菜单、批量操作、刷新、关闭。
- 空/加载中/部分结果/完成/取消/错误状态齐全。
- 键盘：`⌘⇧F` 打开搜索，`Esc` 取消，方向键/Enter 打开，`⌘A` 全选。

**Out of scope**：正则、Spotlight、内容搜索、智能文件夹（见 V11-09/V11-10）。

**验收标准**

- [ ] 10k 项目录的当前目录 filter 仍 <150ms，无主线程卡顿。
- [ ] 本地 SSD 上递归搜索首个结果 <1s；100k 项扫描期间 UI 可交互、有进度和结果计数。
- [ ] 取消后 200ms 内停止，已找到的结果保留；不崩溃。
- [ ] 符号链接循环不会死循环；package 不下钻；隐藏文件跟随现有开关。
- [ ] 无权限目录跳过并计数，结果页可查看“跳过 N 个目录”的摘要。
- [ ] 搜索结果标签页与普通文件夹标签互不影响；批量操作后结果自动刷新，已删除项有明确状态。
- [ ] 无主线程文件 IO（用 Instruments/signpost 证明）。
- [ ] 单元测试覆盖：matcher、scope、取消、符号链接循环、Unicode/大小写、权限错误；UI 测试覆盖基本搜索流程。
- [ ] VoiceOver 标签完整，键盘可完成全流程。

**Test plan**：构造嵌套目录、符号链接循环、无权限目录、Unicode 文件名、package、隐藏文件；10k/100k 性能夹具；SMB 手动搜索验证部分结果与取消。

**风险**：SMB 延迟高；先按文件名匹配，不预先 stat 每个文件；结果批量刷新节流；不要把递归搜索做成同步全量遍历。

# V11-02 [P0] 基础文件操作：复制副本 / 简介 / 新建文件 / Move To & Copy To

**Labels**：`area:file-ops` `priority:P0` `size:M` `needs:tests`  
**Depends on**：—（撤销验收依赖 V11-06）

**Scope**

- **复制副本（Duplicate）**：生成 `原名 copy.ext`，冲突时自动递增；复用安全传输/队列；可撤销。
- **显示简介（Get Info）**：名称、路径、类型、大小（文件夹异步计算、可取消）、创建/修改/拍摄时间、所有者、POSIX 权限、Finder 标签；复制路径。
- **新建文件（New File）**：空文件，支持扩展名；冲突和权限错误处理。
- **Move To / Copy To**：目标文件夹选择器；复用现有队列、冲突 UI、预检；记住上次目标；键盘快捷键。
- 全部支持多选、右键菜单、主菜单、禁用态正确。

**Out of scope**：批量重命名（V11-11）、压缩/解压（V11-03）、ACL 编辑、扩展属性编辑。

**验收标准**

- [ ] Duplicate 不绕过 `SafeFileOperations`/队列；覆盖失败时旧目标不变；成功后可在 V11-06 撤销。
- [ ] Get Info 的文件夹大小计算不阻塞 UI，可取消；网络卷显示加载中/失败状态；关闭面板后任务取消。
- [ ] New File 在已存在同名文件时不覆盖，给出冲突提示；无权限时显示系统错误而非静默失败。
- [ ] Move To / Copy To 完整复用冲突处理和预检；取消后不产生半成品；记住上次目标目录。
- [ ] 所有操作在右键菜单和主菜单都有入口；多选时行为一致；无选择/多选/只读目录的禁用态正确。
- [ ] 测试覆盖冲突、权限失败、取消、网络目标；不出现主线程 IO。

**风险**：文件夹大小在 SMB 上可能很慢；必须异步、可取消，并允许先显示“计算中”。

# V11-03 [P0] 压缩/解压基础能力（zip/tar/gz/bz2）

**Labels**：`area:archive` `priority:P0` `size:M` `needs:tests`  
**Depends on**：—（发布阶段复用安全写入）

**Scope**

- 压缩选中项为 zip/tar/gz；选择目标位置和文件名。
- 解压 zip/tar/gz/bz2 到目标文件夹。
- 使用 `Process` + 参数数组调用系统工具（`ditto`/`tar`），禁止 shell 字符串拼接。
- 输出先写临时文件/临时目录，成功后再安全发布；失败清理临时产物。
- 解压前预检条目：拒绝绝对路径、`..`、符号链接逃逸；解压到 staging 后再移动到目标。
- 取消时终止子进程并清理 staging。

**Out of scope**：应用内压缩包浏览（VFS）、7z/rar、密码压缩包、GBK 文件名修复、分卷（v1.13）。

**验收标准**

- [ ] zip/tar/gz 压缩成功，输出可被系统工具正常打开；取消/失败不留下半成品。
- [ ] zip/tar/gz/bz2 解压成功；嵌套目录、Unicode 文件名、空目录、空压缩包均正确。
- [ ] 恶意条目（`../`、绝对路径、符号链接逃逸）被拒绝，staging 不发布，用户看到明确错误。
- [ ] 大压缩包操作期间 UI 可交互；取消后子进程终止，临时目录清理。
- [ ] 目标已存在同名项时走冲突 UI，不静默覆盖。
- [ ] 测试覆盖：zip slip、绝对路径、符号链接、损坏压缩包、Unicode、取消、冲突。
- [ ] 代码审查确认无 shell 注入面；`Process` 只传参数。

**风险**：不同系统工具对元数据/密码支持不一致；v1.11 只承诺基础可用，不承诺完整元数据保留；解压后权限按 staging 结果保守处理。

# V11-04 [P0] 传输预检（Transfer Plan）

**Labels**：`area:transfer` `priority:P0` `size:M` `needs:tests`  
**Depends on**：V11-05、V11-07

**Scope**

- 复制/移动开始前显示“传输计划”sheet：
  - 源/目标、文件数、总大小、目标剩余空间、冲突数量、权限警告、是否网络卷。
  - 按操作类型计算峰值空间：复制/覆盖需要额外一份；跨卷移动需要一份；同卷移动通常为 0。
  - “开始传输”/“取消”；计算过程可取消。
- 默认只对超过阈值（建议 >100 项或 >1GB）或存在冲突的操作显示；小操作保持现有流程。
- 不替代逐文件冲突处理；冲突仍在真正执行时逐个确认。
- 最终执行前重新验证源/目标状态，预检结果不作为安全保证。

**Out of scope**：带宽预估、传输时间精确预测、后台计划任务。

**验收标准**

- [ ] 大操作/有冲突时默认显示计划；小操作不被打断。
- [ ] 计算在后台执行，有进度；取消后不产生任何文件系统变化。
- [ ] 目标空间不足（考虑 staging 峰值）时阻止开始并给出所需/可用字节；SMB 容量未知时显示警告但允许继续。
- [ ] 预检能识别冲突数量和权限问题；实际执行仍然走现有安全校验，不能因预检通过而跳过。
- [ ] 取消/关闭 sheet 后队列状态正确，不留下 pending 项。
- [ ] 测试覆盖 ENOSPC、冲突、权限、取消、未知容量、巨型目录。

**风险**：巨型目录预检本身很慢；允许用户跳过预检，但保留冲突 UI；不要把预检做成不可取消的全量扫描。

# V11-05 [P0] 传输队列：暂停/恢复/重试

**Labels**：`area:transfer` `priority:P0` `size:M` `needs:tests`  
**Depends on**：—

**Scope**

- 队列级暂停：停止启动新任务；正在运行的任务继续完成；恢复后继续 pending。
- 重试失败项：单条重试、全部重试；复用原 source/destination/operation。
- 失败项保留在队列中，直到重试或手动移除；不重复写历史。
- 取消在暂停状态下仍可用。
- 明确不实现“文件中间暂停/断点续传”（v1.12+）。

**验收标准**

- [ ] 并发 1/3/5 下暂停/恢复行为一致；运行中任务不被强杀。
- [ ] 重试会重新校验目标状态；目标已变化时重新走冲突处理，不盲目覆盖。
- [ ] 重试成功/失败都正确更新历史和进度；不产生重复条目。
- [ ] 暂停时取消 pending/running 项行为正确；队列不会卡死。
- [ ] 测试覆盖暂停/恢复/重试成功/重试失败/取消/并发切换。

**风险**：状态机容易出竞态；先做队列级暂停，不做文件级暂停；所有状态变更在 MainActor，IO 在后台。

- [x] 批量撤销部分失败时报告明细，成功项已恢复、失败项保持原状。
- [x] 复制撤销不会删除用户后来修改过的文件。
- [x] 覆盖操作显示不可撤销；不会出现“假撤销”。
- [x] 退出应用后撤销栈清空，行为在 UI 中说明。
- [x] 测试覆盖成功、状态变化、批量部分失败、覆盖不可撤销、复制后修改目标。

**风险**：macOS 没有公开的“从废纸篓恢复”API；Trash 撤销可能涉及 `~/.Trash` 或外置卷 `.Trashes` 权限，先列为 P1。

# V11-07 [P0] 传输安全硬化：SMB/exFAT/ENOSPC/断线/残留恢复

**Labels**：`area:safety` `area:transfer` `priority:P0` `size:L` `needs:tests`  
**Depends on**：V11-04、V11-05

**Scope**

- 目标卷能力探测：缓存 `RENAME_EXCL`/`RENAME_SWAP` 支持情况。
- SMB/exFAT 不支持原子 swap 时的回退路径：
  - staging 完成后，旧目标改名为同目录 backup；
  - staging 发布为目标；
  - 删除 backup；任一步失败按顺序回滚，源/旧目标不丢失。
- ENOSPC 处理：staging 失败清理，旧目标/源保持不变；错误中包含所需/可用空间。
- 断线处理：不发布半成品；队列失败；重连后重试；staging 可清理或可恢复。
- 启动时扫描已知目标根目录（最近传输历史）中的 `.maxplorer-transfer-*`：
  - 展示恢复提示；
  - 不自动删除存在歧义的数据；
  - 提供“保留/清理”操作。
- 扩充故障注入测试：APFS、exFAT 稀疏镜像、ENOSPC、断线模拟；SMB 手动矩阵 + 收据。

**Out of scope**：恶意外部并发修改的完全防护、文件系统级快照/事务日志、硬链接拓扑保留。

**验收标准**

- [ ] 目标卷能力探测有缓存，不造成 UI 卡顿。
- [ ] SMB/exFAT 上覆盖操作成功，或安全失败并给出明确原因；任何失败路径都不丢源文件或旧目标。
- [ ] ENOSPC 中途失败时 staging 清理，源/旧目标完好；错误信息包含空间数据。
- [ ] 断线后不出现“半成品已发布”；重连后重试可成功；staging 有明确归属。
- [ ] 启动恢复提示能发现残留；用户可选择保留/清理；默认不自动删除。
- [ ] APFS/exFAT 自动化测试通过；SMB 手动测试矩阵与日志归档；原有 30 项安全回归全绿。
- [ ] 文档更新：明确支持/不支持的文件系统与语义，不再把未验收场景写成已保证。

**风险**：SMB 的 rename 语义因服务器而异；回退路径必须做真实共享测试；不要把“安全失败”当成“已支持”。
