# MaXplorer

MaXplorer 是一款原生 macOS 文件管理器，将 Windows 资源管理器风格的导航与精致、现代的 Mac 使用体验相结合。快速浏览文件，处理本地与网络存储中的内容，并随时查看和掌控每一项文件操作。

## 功能

- **真正的标签页浏览** — 最多可在标签页中打开 50 个文件夹，拖动调整顺序、复制标签页，以及按名称排序。所有标签页之间的剪贴板和收藏夹保持同步。
- **剪切和粘贴以移动文件** — 使用 `⌘X` / `⌘V` 移动文件，符合 Windows 用户的使用习惯。支持在本地磁盘与已挂载的网络卷之间移动，无需依赖访达中不易发现的修饰键操作方式。
- **直接粘贴到另一个标签页** — 复制或剪切项目后，通过目标标签页的上下文菜单直接粘贴，无需离开当前正在查看的文件夹。
- **清晰、流畅的复制与移动队列** — 在专用队列中查看所有正在进行的传输，包括单个文件进度、总体进度、传输速度和预计剩余时间。网络冲突检查和进度更新不会阻塞界面，您还可以选择 MaXplorer 同时处理的文件数量。
- **逐项处理文件冲突** — 粘贴或拖放文件时，如果目标中已有同名文件，可针对每一次冲突选择“覆盖”“全部覆盖”“跳过”“全部跳过”或“取消”，操作结果清楚可控。
- **内置空间分析器** — 将任意文件夹扫描为可交互、按颜色分类的矩形树图，实时查看扫描进度，并直接打开大体积项目、浏览其所在位置或复制其路径。无需另行安装磁盘用量可视化工具。
- **集成终端** — 在当前标签页内打开终端面板，并自动切换到该文件夹；也可通过工具栏或上下文菜单启动独立的终端窗口。
- **即时文件夹筛选** — 按 `⌥⌘F` 聚焦实时筛选框，即时缩小当前文件夹中的显示范围，无需 Spotlight 索引。
- **内置网络浏览** — 发现本地 SMB 服务器，浏览已挂载的 SMB/AFP 卷，直接连接已知服务器，并通过已记住的服务器列表快速重新连接。连接成功后会在新的 MaXplorer 标签页中打开，并正确显示已挂载网络存储的可用空间。
- **可自定义且共享的侧边栏** — 将任意文件夹固定到收藏夹，移除不使用的内置位置，通过拖动重新排列固定项目，并在所有已打开的标签页中同步这些更改。侧边栏底部始终提供“设置”和“关于”入口。
- **广泛支持拖放** — 将文件拖放到文件夹行或标签页上以复制或移动；拖动悬停切换功能会自动激活目标标签页。
- **快速预览和打开方式** — 按 Space 预览选中的文件，并通过同一文件的上下文菜单选择兼容的应用程序。
- **个性化外观** — 选择浅色、深色或跟随系统的外观；可选的交替底色文件行；macOS 风格的蓝色文件夹图标或 Windows 风格的黄色文件夹图标；以及以元素为灵感的颜色主题：默认、💧 水、🌍 地、🔥 火或 🌬️ 风。每种主题都会应用到窗口、标签页、侧边栏、工具栏、表单、文件显示区域和终端，同时保留浅色／深色模式的明暗特征。
- **Liquid Glass 设计** — 工具栏、筛选框、路径栏、侧边栏和设置界面采用 macOS 26 Liquid Glass，让 MaXplorer 与系统其他部分保持协调。“风”主题提供透明度更高、带灰色色调的视觉效果。
- **按需集成访达** — 通过上下文菜单或键盘快捷键在访达中显示任意项目，同时继续使用 MaXplorer 的工作流程。

## 键盘快捷键

### 文件与文件夹操作
| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开选中的项目 |
| `Space` | 快速预览选中的项目 |
| `⌘⇧N` | 新建文件夹 |
| `⌘⇧R` | 重命名选中的项目 |
| `⌘⌫` | 将选中的项目移到废纸篓 |
| `⌃⌘R` | 在访达中显示选中的项目 |
| `⌘⇧T` | 在选中的项目／当前文件夹位置打开终端 |

### 编辑与剪贴板
| 快捷键 | 操作 |
| --- | --- |
| `⌘C` | 复制选中的项目 |
| `⌘X` | 剪切选中的项目，在粘贴时移动 |
| `⌘V` | 粘贴已复制或剪切的项目 |
| `⌘A` | 选择当前文件夹中的所有项目 |
| `⌘⌥C` | 复制选中项目的路径；未选中任何项目时，复制当前文件夹路径 |

### 视图
| 快捷键 | 操作 |
| --- | --- |
| `⌥⌘F` | 聚焦筛选框 |
| `⌘R` | 重新载入当前文件夹 |
| `⌘⇧.` | 显示或隐藏隐藏文件 |
| `⌘⇧A` | 显示或隐藏替身 |

### 标签页
| 快捷键 | 操作 |
| --- | --- |
| `⌘T` | 新建标签页 |
| `⌘⇧D` | 复制标签页 |
| `⌃⇥` | 选择下一个标签页 |
| `⌃⇧⇥` | 选择上一个标签页 |

### 导航
| 快捷键 | 操作 |
| --- | --- |
| `⌘[` | 后退 |
| `⌫` | 后退（文件列表获得焦点时） |
| `⌘]` | 前进 |
| `⌘↑` | 上一级文件夹 |
| `⌘⇧G` | 前往文件夹 |
| `⌘⇧H` | 个人文件夹 |
| `⌘K` | 连接服务器 |

## 平台支持

MaXplorer 面向 macOS 26 及更新版本（部署目标为 26.5），因此直接采用最新的系统视觉效果，尤其是 Liquid Glass，无需进行可用性检查。

当前的 macOS 26 增强功能：

- 工具栏按钮组、筛选框、路径栏和侧边栏采用 Liquid Glass 界面。
- “关于”和“设置”主界面采用 Liquid Glass 卡片，颜色主题延伸到整个应用窗口及相关表单。
- “风”颜色主题在应用各界面中采用透明度更高的材质。
