# 更新记录

## 2026-10-23 — v1.10

- 界面完整支持简体中文本地化，覆盖菜单、设置、空间分析器、复制队列和预览窗口。
- 改进快速预览：支持 Quick Look、显式文本编码、旧版 Office 文档提示，修复密码提交，并优化窗口缩放与跨显示器定位。
- 复制和移动改为事务式处理：先写入私有暂存目录并校验，再原子发布，同时保留权限、ACL、扩展属性、资源分支和时间戳；取消或失败不会破坏原目标。
- 大幅提升大文件夹浏览性能：内容分批渐进显示，排序和筛选移至主线程之外，类型描述按扩展名缓存，图标和卷信息异步加载。
- 空间分析器采用限流并发扫描，并优化树图布局，大型扫描及窗口缩放更流畅。

## 2026-10-13 — v1.09

- 在文件和文件夹图标上添加了访达标签颜色圆点。
- 按文件夹记住排序方式，并可在“设置”中配置默认排序字段和顺序。
- 添加了用于显示或隐藏列的原生列标题菜单，与工具栏中的列选择器同步，并提供“重置列”功能。
- 通过缓存排序和筛选后的项目，提高了列表显示性能。
- 修复了在 macOS 27 上使用“默认”主题时，浏览器工具栏（导航按钮和筛选框）被隐藏的问题。
- 修复了侧边栏导航在视图更新期间发布状态变更的问题。
- 将最低 macOS 版本提升至 26，并解决了 Swift 并发警告。

## 2026-08-17 — v1.08

- 为空间分析器添加了“所有文件”和“逐层浏览”模式，并可配置默认模式。
- 在“逐层浏览”模式中添加了文件夹面包屑导航，并支持双击进入文件夹。
- 改进了“逐层浏览”可视化，采用 WinDirStat 风格的比例矩形树图，在反映相对大小的同时，让较小的项目也保持可见。
- 统一了“逐层浏览”模式中文件夹图块的颜色，使其与默认文件夹颜色一致。
- 修复了网络卷可用空间错误显示为零的问题，并使空间分析器中的已用／可用容量显示与标准文件夹导航保持一致。

## 2026-08-11 — v1.07

- 在空间分析器旁添加了专用的“复制队列”标签页，切换标签页时传输进度仍能正确持续更新。
- 为已完成的复制和移动操作添加了复制队列历史记录，可在“文件传输”设置中配置，默认仅保留最近 100 条。
- 为正在进行的传输添加了可点击的目标文件夹链接；选择链接后会切换到已有的文件夹标签页，或打开新的标签页。
- 改进了传输取消和失败处理：已取消的任务会立即消失，进度会正确停止，意外中止的原因会显示出来，并移除未完成的目标文件。
- 将文件系统工作移出主线程，并限制进度更新频率，优先保障本地及已挂载网络位置上的复制和移动操作期间的界面响应。
- 改进了网络卷上的删除操作：当卷不支持废纸篓时永久删除文件，并显示准确的确认提示。
- 将空间分析器和复制队列放在侧边栏“设备”下方；没有可用设备时，隐藏“设备”分区。
- 改进了默认窗口布局，确保启动时完整显示当前文件夹路径和筛选控件。

## 2026-08-03 — v1.06

- 添加了“外观”设置分组，包含浅色、深色和跟随系统模式、可选的交替底色文件行，以及 Mac 风格或 Xplorer 风格的文件夹图标。
- 添加了应用全局元素颜色主题：默认、💧 水、🌍 地、🔥 火和 🌬️ 风。主题应用于窗口、标题栏、标签页、侧边栏、工具栏、表单、文件显示区域、空间分析器和集成终端；“风”主题提供更透明的视觉效果。
- 改进了“设置”布局，加宽控件，并将“外观”“工作区”和“文件传输”拆分为独立分组。
- 为浏览器标签页添加了关闭控件，并修复了侧边栏尺寸、选择状态及其常驻的“设置”／“关于”控件。
- 记住成功的服务器连接，以便快速重新连接，并在新的 MaXplorer 标签页中打开已连接的位置。
- 将冲突预检查移出主线程，并合并进度更新，保持复制和移动开始时的流畅响应，尤其是在目标为网络位置时。
- 更新了 README 中的功能介绍。

## 2026-07-29 — v1.05

- 添加了收藏夹持久化，并将收藏路径与浏览器标签页及文件浏览器导航集成。
- 添加了通过标签栏粘贴的支持，并共享浏览器／文件剪贴板的基础处理机制。
- 改进了文件系统发生更改后的文件刷新行为。
- 优化了复制队列行为，使进度和完成状态的处理更清楚。
- 改进了空间分析器图块的悬停提示，首先显示大小，随后显示项目名称和完整路径。
- 使“关于”界面中的 README 和更新记录弹窗支持调整大小。
- 更新了 README 中的功能介绍，包括相较于访达的优势。
- 改进了应用配色方案的处理，并优化了侧边栏布局。

## 2026-07-12 — v1.04

- 剪切和粘贴现在可以在本地磁盘与已挂载的网络卷之间可靠地移动文件。
- 在“帮助”菜单中添加了 **MaXplorer README**。
- 状态栏显示选中项目数量及选中文件的总大小；清除选择后，恢复显示通常的项目数量。
- 从外部添加、移除、重命名或修改项目时，当前文件夹会自动刷新。
- 已挂载的网络卷现在可以正确报告可用空间，不再显示零字节可用。
- 集成终端现在支持标准的 Command-C 和 Command-V 剪贴板快捷键。

## 2026-07-11

- 添加了集成终端（同时保留标准的独立窗口终端）。

## 2026-07-03（稍后）— v1.02

- 新增 **空间分析器**（磁盘存储分布图）：以 GrandPerspective 风格的矩形树图展示所选文件夹下的全部内容，可从侧边栏、工具栏按钮、独立颜色的标签页或文件夹右键菜单打开。同一时间仅存在一个分析器标签页。
- 扫描完全在后台运行（界面保持响应），显示实时进度，始终提供“取消扫描”按钮，并在切换标签页后继续运行。
- 图块依据可编辑的 `file-categories.json` 按文件类别着色（视频、音乐、图像、应用、归档文件、文档）。右键点击图块可选择“打开”“浏览所在位置”或“复制路径”。
- 扫描时忽略符号链接和访达替身，仅测量实际项目。
- 状态栏现在显示卷的“已用／可用”空间（含可用空间百分比），替代当前文件夹路径。
- 上下文菜单项目现在显示对应的键盘快捷键。
- 侧边栏中的“收藏夹”和“网络”分区可以折叠／展开，并在下次运行时记住状态。
- 长按文件行可重命名；悬停提示跟随光标，并在右键点击时关闭。

## 2026-07-03

- 冲突解决现在按文件逐一进行：每次冲突都会显示文件名，并提示选择“覆盖”“全部覆盖”“跳过”“全部跳过”或“取消”。带“全部”的选项会应用于队列中的剩余项目，不再继续提示。
- 冲突解决也适用于移动操作（拖放到文件夹、剪切粘贴），不再仅限于复制。
- 添加了“复制标签页”（⌘⇧D）。
- ⌘F 可直接通过键盘聚焦筛选框。
- “关于”界面添加了 README 按钮，可在弹窗中打开项目 README，并使用与更新记录相同的 Markdown 查看器进行渲染。
- 将 README 中的键盘快捷键表按类别重新组织，并更新内容。
- 将 README 中的“当前实现状态”分区替换为面向用户的“功能”分区。
